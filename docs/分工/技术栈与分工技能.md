# 技术栈与分工技能地图

> 2026 微信小程序开发大赛 · 《宿舍物语》
> 归档日期：2026-09-24 · 冲刺窗口：9/25–10/17
> 用途：作为三份分工文档的技术底座，明确「全员用哪套技术、每个人重点掌握什么」。

## 一、项目整体技术栈（全员须了解）

| 层级 | 技术选型 | 说明 | 对应模块 |
| --- | --- | --- | --- |
| 前端 | 微信小程序原生（WXML / WXSS / JS） | 遵循《微信小程序设计指南》，微信内原生流畅运行 | 全部页面与组件 |
| 后端 | 微信云开发（云函数 + 云数据库 + 云存储） | 免运维、与小程序无缝集成，适合短周期 | 全部后端逻辑 |
| AI 能力 | 云函数内调用 AI 接口（结构化 Prompt + JSON 输出） | 覆盖排班、分析、文案/事件生成 | 阶段3 全部 AI 功能 |
| 定时任务 | 云开发定时触发器 | 驱动每日提醒、每周总结、低库存检测 | 提醒 / 周报 / 补货 |
| 版本管理 | Git + GitHub（仓库 dorm-story） | 分支开发、云函数按功能独立部署 | 团队协作 |
| 开发工具 | 微信开发者工具 + Node.js（LTS） | 调试、真机预览、上传体验版 | 全员 |

## 二、三位成员的技术栈要求

### 成员甲 · 骨架与账号主程

| 技术栈 | 掌握程度 | 用途 |
| --- | --- | --- |
| WXML / WXSS / JS | 熟练 | 全局框架、页面布局、底部导航 |
| 小程序组件与路由（navigator / tabBar / 自定义组件） | 熟练 | 建/加入宿舍、登录授权、公共组件 |
| 微信登录与鉴权（getUserProfile / 云登录） | 熟练 | 账号体系、openid 入库 |
| 云数据库基础增删改查（db.collection） | 熟练 | dorm / member / user 集合维护 |
| WXS 与简单动画 | 了解 | 经验条、星级等轻量动效 |
| Node.js 基础 | 了解 | 读懂并调试云函数 |

### 成员乙 · 闭环与协作主程

| 技术栈 | 掌握程度 | 用途 |
| --- | --- | --- |
| 云开发环境（数据库 / 云函数 / 定时触发器） | 熟练 | 排班、打卡、提醒的后端逻辑 |
| 云函数编写与调用（Node.js + wx-server-sdk） | 熟练 | scheduleDuty / doCheckin 等 |
| 云数据库查询与更新（聚合、条件） | 熟练 | 排班公平性、打卡状态 |
| 小程序订阅消息（模板 ID / 授权 / 推送） | 熟练 | 值日提醒、公告通知 |
| WXML / WXSS / JS 页面开发 | 熟悉 | 值日页、打卡页、日历、费用页 |
| JS 数组/日期处理（轮转算法、日期计算） | 熟练 | 规则版排班算法 |

### 成员丙 · 引擎统筹与 AI 主程

| 技术栈 | 掌握程度 | 用途 |
| --- | --- | --- |
| Node.js + 云函数（wx-server-sdk） | 熟练 | addExp、属性/等级计算、aiLog 落库 |
| 结构化 Prompt 设计与 JSON 输出解析 | 熟练 | AI 排班、活跃度、事件/挑战、周报 |
| AI 接口调用（遵循微信 AI 生态接入指引） | 熟练 | 阶段3 全部 AI 功能 |
| 云数据库聚合与批量更新 | 熟练 | 属性加权计算、经验流水 |
| 数据可视化组件（雷达图 / 进度条） | 熟悉 | 属性面板、等级展示 |
| 文档与项目管理 | 熟练 | 进度看板、作品材料、报名提交 |

## 三、必装工具与环境（开工前一次性就位）

1. **微信开发者工具**（微信公众平台官网下载）
2. **Node.js LTS**（云函数运行时）
3. **Git + GitHub 账号**（已建仓库 dorm-story）
4. **微信公众平台小程序账号**：AppID + 已开通**云开发环境**（未就位则为阶段1 最大阻塞项）
5. **TCB 云开发命令行**（可选，用于云端函数批量部署）

## 四、常用依赖与资源

| 类别 | 依赖 / 资源 | 用途 |
| --- | --- | --- |
| 云函数 | `wx-server-sdk` | 云函数调用云数据库标准库 |
| AI 调用 | 按《微信开发者接入 AI 生态指引》选择接入方式 | 结构化输出，过程落 `aiLog` |
