## 四、负责的数据集合与对外接口（契约）

**集合**：`dorm`（宿舍·等级·经验·属性）、`member`（成员）、`user`（openid 鉴权）

**对外提供（云函数）**：
- `login`（登录鉴权）
- `createDorm` / `joinDorm`（建/加入宿舍）
- `getDorm` / `getMembers`（宿舍与成员信息）

**依赖别人**：首页等级/属性展示 → 丙的 `getAttrs` / `getLevel`

## 五、与队友的协作点

- **对乙**：首页需挂乙的值日/打卡入口；乙的排班结果要能回显到首页面板。
- **对丙**：首页等级、经验条、属性雷达图直接调丙的接口，别自己算数值。
- **对齐方式**：公共组件、全局样式统一由你维护；云函数接口按「集合 + 字段」口径对齐（见 docs/项目开发路线.md 数据模型）。

## 六、技能与学习重点（对应 docs/零基础项目学习路线.md）
