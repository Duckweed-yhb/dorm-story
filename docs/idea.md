# 《宿舍物语》· 与AI共生的宿舍经营小程序（产品构思）
> 2026 微信小程序开发大赛 · 主题「与AI共生」
> 定稿方向：把宿舍管理做成一个可共同经营、升级、完成任务的「轻 RPG」小程序

## 一句话定位
让整个宿舍成为一个可以**共同经营、升级、完成任务**的游戏单位，把枯燥的日常琐事（扫地、打卡、公告）转译为游戏语言（副本、经验值、等级、属性），核心心智从「今天我要不要扫地」变成「我们宿舍今天能不能完成副本」。

## 目标用户
- 在校大学生 / 研究生宿舍成员（3–6 人合住场景）
- 重视宿舍氛围与效率、有一定游戏化偏好的年轻用户
- 宿舍长 / 寝室管理者，需要低成本的协作与提醒工具

## 核心价值主张
| 痛点 | 传统方式的问题 | 《宿舍物语》的解法 |
|---|---|---|
| 值日安排不公平、常忘记 | 口头约定，靠自觉，纠纷多 | AI 自动排班 + 提醒 + 历史公平性分析 |
| 公共物品经常缺货 | 发现即缺，事后补救 | 物品台账 + 低库存提醒 + 任务化补货 |
| 宿舍氛围松散、缺乏认同感 | 无量化反馈，努力被忽视 | 宿舍等级、属性、经验值可视化成长 |
| 沟通靠微信群，信息易淹没 | 公告刷屏、日历各用各的 | 统一公告 + 共享日历 + 打卡看板 |

## 基础功能模块（九大）
自动安排值日 / 值日提醒 / 宿舍任务 / 宿舍费用（AA·分摊）/ 公共物品（台账·补货）/ 公告 / 共享日历 / 宿舍成员（档案·角色）/ 共同打卡

## 游戏化系统设计
- **宿舍属性**：五维属性（卫生、团结、活跃、秩序、自律），以 1–5 星展示，随真实行为数据动态变化，对应一个宿舍总等级（如 Lv.8）
- **经验值体系**：完成值日 +10 XP、补充公共物品 +15 XP、全员打卡 +30 XP、宿舍活动 +50 XP、连续 7 天完成任务 +100 XP；经验值累积驱动等级成长，解锁称号、皮肤、专属公告样式等轻量激励，形成「真实行为 → 可见成长」正反馈闭环

## AI能力接入（与AI共生）
AI 承担**排班、分析、生成**三类核心工作：
1. 自动生成值日安排（结合成员空闲时间、历史完成情况）
2. 根据历史情况调整任务（识别拖延 / 不公平分配并自动纠偏）
3. 分析宿舍活跃度（识别活跃 / 沉默成员，辅助宿舍长关注冷门问题）
4. 发现长期未完成的任务并主动预警
5. 自动生成宿舍事件 / 根据成员行为生成挑战（如「本周无人补充纸巾」触发趣味任务）
6. 生成每周宿舍总结（打卡、任务、属性变化汇总成周报文案）

所有 AI 调用统一记录到 `aiLog` 集合，过程留痕、可追溯、可审计，遵循大赛「严禁 AI 生成抄袭作品、违规套用现成源码」要求，核心创意与实现团队原创。

## 技术方案与数据模型
- 前端：微信小程序原生（WXML/WXSS/JS），或 uni-app（可选）
- 后端：微信云开发（云函数 + 云数据库 + 云存储），免运维
- AI：云函数内调用 AI 接口（结构化 Prompt + JSON 输出），规则版兜底
- 定时：云开发定时触发器（每日提醒 / 每周总结 / 低库存检测）
- 核心集合：`dorm`（宿舍·等级·经验·属性）、`member`、`duty`（值日）、`task`、`checkin`（打卡）、`item`（物品）、`announcement`、`expense`、`aiLog`

## 开发路径（由内到外，任意阶段可交付）
① 打通骨架：账号体系 + 建宿舍/加入宿舍 + 基础导航
② 跑通最小闭环：值日排班（规则版）+ 打卡 + 经验值引擎（完成行为 → 经验值 → 属性变化可见）
③ 补齐协作模块：任务、公共物品、公告、共享日历、费用
④ 接入 AI 能力：从自动生成值日安排起步，扩展到分析、事件、周报
⑤ 体验打磨与稳定性：空状态、加载态、异常兜底、订阅消息节奏
⑥ 上线与材料准备：正式发布 + 作品介绍 PDF + 报名材料提交

## 风险与兜底
- AI 响应慢/不稳定 → 所有 AI 功能保留「规则版」兜底逻辑
- 周期短 → 优先①-③核心闭环，④-⑥为增强项按进度取舍
- 多人协作冲突 → Git 分支管理、云函数按功能独立部署
- 审核/上线不通过 → 预留 ≥2 天缓冲期整改
