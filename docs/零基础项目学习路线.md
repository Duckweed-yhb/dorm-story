# 零基础项目学习路线

> 从零开始，学会独立开发《宿舍物语》所需的全部技能
> 2026 微信小程序开发大赛 · 参赛项目《宿舍物语》
> 文档生成日期：2026年9月22日

## 一、路线说明

本路线面向没有微信小程序开发经验、但有基本电脑操作能力的团队成员。目标不是"系统学完再开发"，而是"边学边做"：每学完一个阶段，立刻对应到项目里的一个真实模块，避免学习与开发脱节。

由于大赛报名与提交窗口为2026年7月17日–10月17日，当前时间已进入冲刺期，学习节奏必须压缩到与《项目开发时间安排》并行进行，建议团队按角色拆分学习内容（见第七章），不要求每人学完全部路线。

## 二、预备知识（0.5–1天）

- 了解小程序 vs App vs 网页的区别，明确小程序"轻量、免安装、依托微信生态"的定位
- 注册微信公众平台小程序账号，获取 AppID
- 安装微信开发者工具，跑通官方 Hello World 示例
- 通读《微信小程序设计指南》与《微信小程序平台运营规范》，明确本次开发的合规边界

## 三、阶段一：小程序前端基础（3–4天）

| 学习内容 | 对应项目模块 | 建议资源 |
| --- | --- | --- |
| WXML / WXSS 基础语法与布局 | 所有页面的基础骨架 | 微信官方文档《小程序开发指南》 |
| JS 逻辑层：data / event / 生命周期 | 打卡按钮、任务勾选等交互 | 官方文档 + 官方示例小程序 miniprogram-demo |
| 组件与路由：navigator、tabBar、自定义组件 | 底部导航（值日/任务/宿舍/我的） | 官方组件库文档 |
| WXS 与简单动画 | 经验值增长动效、星级属性展示 | 官方文档 WXS 章节 |

阶段目标：能独立完成一个静态页面（如"宿舍属性面板"），并让按钮点击产生页面反馈。

## 四、阶段二：云开发与数据（3–4天）

| 学习内容 | 对应项目模块 | 建议资源 |
| --- | --- | --- |
| 云开发环境搭建（云数据库/云函数/云存储） | 宿舍、成员、任务等数据存储 | 微信云开发官方文档 |
| 数据库增删改查（db.collection） | 打卡记录、任务状态更新 | 云开发数据库 API 文档 |
| 云函数编写与调用（Node.js） | 自动排班、经验值计算等后端逻辑 | 云函数官方示例 |
| 定时触发器（云函数定时任务） | 每日提醒、每周总结生成 | 云开发定时触发器文档 |

阶段目标：能把一个前端页面的数据存进云数据库，并在页面刷新后正确读取展示。

## 五、阶段三：AI能力接入（2–3天）

- 阅读官方《关于开发者接入微信AI生态的指引》，明确可用的AI接入方式与合规要求
- 学习通过云函数调用外部/内置AI接口，理解 Prompt 输入与结构化输出（如返回JSON格式的排班结果）
- 练习：用AI接口生成一句"宿舍周报文案"，并展示到小程序页面上
- 练习：设计一个简单排班算法（先规则版，再逐步引入AI辅助调整），理解规则兜底 + AI优化的组合思路

阶段目标：能让小程序调用一次AI接口并把结果正确落库、正确展示，全过程保留调用日志以满足"AI使用过程合规可追溯"的要求。

## 六、阶段四：整合与打磨（2天）

- 学习小程序发布流程：开发版 → 体验版 → 提交审核 → 正式发布
- 学习基础的用户体验优化：加载态、空状态、错误提示
- 学习如何生成小程序码、如何撰写符合大赛要求的PDF作品介绍文档

## 七、按角色拆分学习重点

| 角色 | 必学阶段 | 可跳过/简学阶段 |
| --- | --- | --- |
| 前端开发 | 阶段一（重点）、阶段四 | 阶段二可简学，能调用现成云函数接口即可 |
| 后端/云开发 | 阶段二（重点）、阶段三 | 阶段一只需了解页面如何调用数据即可 |
| AI集成 | 阶段三（重点） | 阶段一简单了解，阶段二理解数据结构 |
| 产品/全栈型成员 | 预备知识 + 全部阶段快速过一遍 | 不深入，重点在打通整体流程 |

## 八、学习原则

- 以官方文档为唯一权威来源，避免踩过时教程的坑（小程序API更新较快）
- 每个知识点学完立刻写一小段代码验证，不做纯理论阅读
- 遇到卡点优先查官方文档 + 官方示例代码 miniprogram-demo，其次再搜索社区方案
- 学习进度与《项目开发时间安排》强绑定：本文档的每个阶段应与开发计划中的对应周次同步完成
