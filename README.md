# 宿舍物语 · 与AI共生的宿舍经营小程序

> 2026 微信小程序开发大赛参赛作品 · 主题「与AI共生」

## 项目简介

**《宿舍物语》**（口号：把宿舍经营成副本）是一款面向高校宿舍的**轻 RPG 经营**微信小程序。它把枯燥的日常琐事（扫地、打卡、公告）转译为游戏语言（副本、经验值、等级、属性），让整个宿舍成为一个可以共同经营、升级、完成任务的「游戏单位」——核心心智从「今天我要不要扫地」变成「我们宿舍今天能不能完成副本」。

**三大亮点：**
- **游戏化经营**：宿舍五维属性（卫生/团结/活跃/秩序/自律）+ 总等级 + 经验值成长，真实行为 → 可见成长
- **九大基础功能**：值日安排与提醒、宿舍任务、费用分摊、公共物品台账、公告、共享日历、成员档案、共同打卡
- **AI 共生**：AI 自动排班、任务纠偏、活跃度分析、事件/挑战生成、每周总结，全过程调用留痕可追溯

不依赖自建服务器（微信云开发），可上线、可运营、可持续。

## 核心功能（MVP）

1. 账号体系 + 建宿舍/加入宿舍（邀请码/二维码）
2. 值日排班（规则轮转 → AI 优化）+ 值日提醒
3. 共同打卡 + 经验值引擎（addExp 云函数）
4. 宿舍任务 / 公共物品 / 公告 / 共享日历 / 费用分摊
5. AI：自动排班、活跃度分析、事件/挑战生成、每周总结（aiLog 留痕）

## 与AI共生

AI 承担**排班、分析、生成**三类核心工作，所有功能保留「规则版」兜底，AI 仅作为增强；调用统一记录到 `aiLog`，遵循大赛「AI 使用过程合规可追溯」要求，核心创意与实现团队原创。

## 技术方案

- 前端：微信小程序原生（WXML/WXSS/JS），或 uni-app（可选）
- 后端：微信云开发（云函数 / 云数据库 / 云存储）
- AI：云函数调用 AI 接口（结构化 Prompt + JSON 输出）
- 定时：云开发定时触发器

## 团队分工

产品/交互、前端（小程序）、后端/云开发、AI 集成（1–2 人可兼多角色，详见《项目开发时间安排》）。
